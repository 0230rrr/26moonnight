中秋渡假別墅轟趴｜本地 HTML 套件

這是單頁內嵌版本，雙擊 index.html 即可直接開啟。
請解壓縮整個資料夾，不要只單獨取出 index.html，因為頁面照片位於 assets/real-photos/。

如果你之後要修改程式：
- 直接修改 index.html 內的 <style> 與 <script> 內容即可。
- 也保留了 assets/styles.css 與 assets/app.js 作為分離版參考。

網站內的 19 張照片皆取自你提供的 Word 文件。
主視覺使用 image1.jpeg，場地全景使用 image3.jpeg，場地日景使用 image7.jpeg。
